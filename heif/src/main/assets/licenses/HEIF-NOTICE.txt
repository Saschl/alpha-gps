Alpha GPS uses libheif 1.23.5 and libde265 1.1.3, under LGPL-3.0-or-later.
Copyright notices and full license texts are in the accompanying COPYING files.
The libraries are built from source and dynamically linked as separate .so files.
Only HEVC decoding is enabled; HEVC encoders are not included.

Unmodified upstream sources are pinned as submodules in heif/src/main/cpp/vendor:
libheif: https://github.com/strukturag/libheif
Version: v1.23.5, commit: 413e2a87e6a70b3eccc3a3adc5801179dd2d9e00
libde265: https://github.com/strukturag/libde265
Version: v1.1.3, commit: ba62bf4cfb3242f3bf0a45617ff09e35236e4d82

Initialize sources with: git submodule update --init --recursive
The CMake build uses these local sources and does not download dependencies.
For Android, build :heif:assembleRelease with Gradle (NDK 29, CMake 3.22.1).
For host decoder tests:
  cmake -S heif/src/main/cpp -B /tmp/alpha-heif-test -DCMAKE_BUILD_TYPE=Release
  cmake --build /tmp/alpha-heif-test --target heif_decoder_test -j 4
  ctest --test-dir /tmp/alpha-heif-test --output-on-failure
