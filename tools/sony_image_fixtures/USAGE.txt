Sony original-image regression tests

Select a small folder of original Sony HIF and JPEG files. Include landscape
and portrait shots, especially 10-bit 4:2:2 HEIF. Use ordinary scenes with
varying brightness: the tests reject blank or nearly uniform decoded images.
The folder can live on an external drive. Nothing modifies the originals.

On macOS, create the expected-values manifest once:

  swift tools/sony_image_fixtures/manifest.swift /path/to/fixtures > /path/to/fixtures/manifest.json

Review its camera model, dimensions, orientation and metadata before accepting
it as the regression baseline. Width/height describe stored pixels, before
orientation. Do not regenerate the manifest to make a failing decoder pass.
The generator uses macOS ImageIO for metadata and reads HEVC configuration
boxes for bit depth/chroma; it does not use the app's conversion code.

iOS simulator:

  ./gradlew :sharednew:iosSimulatorArm64Test -PsonyImageFixtures=/path/to/fixtures --tests '*SonyCameraImageFixtureTest*'

Android emulator/device (start/connect one first):

  ./gradlew :sharednew:connectedAndroidDeviceTest -PsonyImageFixtures=/path/to/fixtures -Pandroid.testInstrumentationRunnerArguments.class=com.sasch.cameragps.sharednew.remote.wifi.SonyCameraImageFixtureTest

The property enables this separate fixture suite. Without it, normal tests run
without external images. An empty manifest, missing file or changed checksum
fails the fixture build; these cases never silently skip tests.
Only selected fixture images should be in this directory: Android packages
the directory into the test APK, never the production app. The iOS simulator
reads the same files directly from the host path; these tests are not intended
for physical iOS devices.

Coverage: decoding, display orientation, nonblank pixels, HEVC configuration,
camera/lens/capture-time/ISO metadata, and production HEIF-to-JPEG conversion.
Android JPEG checks inspect stored pixels and EXIF separately; they do not
assert that the photo viewer applies EXIF rotation. No UI or colour-fidelity
golden tests are included. Fixtures need at least one HEIF for conversion tests.
